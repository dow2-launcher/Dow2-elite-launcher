- Игроки: клик по нику или аватарке (Онлайн, чат, комнаты, своя карточка) открывает меню — упомянуть в чате, статистика игрока, профиль Steam. В чате клик по нику, как раньше, упоминает игрока.
- Онлайн и чат приходят с сервера ладдера одним живым потоком, без опроса каждые несколько секунд; со старым сервером лаунчер читает Онлайн по-старому.
- Чат: «Общий», RU и EN — один чат на трёх языках; ваше сообщение появляется сразу и становится обычным, когда сервер его принял; счётчики непрочитанного на вкладках.
- Серверы: лаунчер сам выбирает зеркало и сервер, которые лучше всего отвечают с вашего компьютера (проверка при запуске и снова, только если сервер перестал отвечать) — для загрузок, чата и обновления самого лаунчера. Видно в Настройки → Серверы.
- Главная: баннер с событиями над новостями; новости раскрываются целиком; ссылки — иконками внизу; ваша статистика рядом с кнопкой выхода.
- Дополнения: по сворачиваемым группам; убранные у всех дополнения скрыты; дополнения, которых больше нет в каталоге, убираются из папки игры; перед запуском лаунчер говорит, что отключил.
- Комнаты: карточки заполняют окно по его ширине.
- Язык лаунчера по умолчанию — язык системы.
