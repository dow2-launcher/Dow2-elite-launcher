- Settings → Online play: how this computer reaches the game's servers, checked by the same rules the add-ons use. Relic: its game servers (open port, delay, over 200 ms is slow) and a stream to the Relic API - with the verdict "fine" or "trouble, forwarding can help" and the button to turn forwarding on. Our servers: every node of the list the ladder signs - the delay over UDP, whether a stream gets through (40 of 1000 bytes; a node that drops it is not used), TCP for information, the nearest one marked - and which one our automatch and forwarding would use, with the state of both ticks. The Check button; the first check runs when the tab is opened. Nothing is checked while the game runs.
